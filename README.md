## 📌 1. LOYIHA HAQIDA

**AuraMarket AI** — bu oddiy internet do‘kon emas, balki sun’iy intellekt (AI) yordamida foydalanuvchilarga mahsulot tanlash, budjetga mos variantlarni saralash va tovarlarni o‘zaro taqqoslashda yordam beruvchi aqlli marketplace platformasi.

Loyiha professional darajadagi UI/UX dizayn (Glassmorphism, Neumorphism, 3D kartalar, Dark/Light rejim), mustahkam Full-Stack arxitektura va sun’iy intellektli shopping maslahatchi bilan to‘liq jihozlangan.

## ✨ 2. ASOSIY IMKONIYATLAR VA XUSUSIYATLAR

### 🎨 2.1. Premium Dizayn va UI/UX
- **Glassmorphism va Neumorphism**: Yumshoq xiralashtirilgan orqa fonlar (backdrop-blur), nafis chegara chiziqlari va ko‘zni charchatmaydigan soya effektlari.
- **3D Mahsulot Kartalari**: Sichqoncha harakatiga moslashuvchan perspektivali kartalar va silliq hover animatsiyalari.
- **Dark va Light Rejim**: Tizimga moslashuvchi va bitta bosish bilan o‘zgaruvchi to‘liq qora/yorug‘ mavzular.
- **To‘liq Responsive**: Mobil telefonlar, planshetlar va katta monitorlar uchun 100% moslashuvchan.
- **O‘zbek Tili va UZS (So‘m) Valyutasi**: Barcha interfeys matnlari, xabarnomalar, texnik tavsiflar to‘liq o‘zbek tilida va narxlar so‘mda shakllantirilgan (`4 250 000 so‘m`).

### 🔍 2.3. Real-Vaqt Qidiruv va Filtrlash

### 🛒 2.4. Savatcha Tizimi
- O‘ng tomondan ochiluvchi qulay va zamonaviy drayver.
- Mahsulot miqdorini oshirish (+) va kamaytirish (-).
- Mahsulotni o‘chirish (savatchadan chiqarish).
- **Avtomatik hisob-kitob**: Mahsulotlar summasi, yetkazib berish haqi (1 000 000 so‘mdan yuqori xaridlarga bepul), promokod chegirmasi va yakuniy to‘lov.
- **Promokod tizimi**: Masalan `AI2025` kodi bilan 10% qo‘shimcha chegirma yoki `START` kodi bilan 50 000 so‘m bonus.
- Ma’lumotlar `LocalStorage`da doimiy saqlanadi.

### 📝 2.5. Buyurtma Berish (Checkout)
- Qabul qiluvchining to‘liq ismi.
- Telefon raqami (`+998 XX XXX-XX-XX` formatida tekshiruv).
- Shahar va viloyatni tanlash (O‘zbekistonning barcha 12 ta viloyati va Toshkent shahri).
- Aniq manzil va kuryer uchun qo‘shimcha izoh.
- **To‘lov turlari**: Naqd pul (qabul qilinganda), Payme, Click, Uzum Pay.
- Buyurtma tasdiqlanganda bayramona konfetti animatsiyasi (`canvas-confetti`) va unikal raqamli (`ORD-XXXXXX`) elektron chek/tasdiqnoma.

### 🤖 2.6. AI Shopping Assistant (Sun’iy Intellekt Maslahatchi)
Platformaning eng asosiy va innovatsion qismi!
- **O‘zbek tilida tabiiy suhbat**: Foydalanuvchi istaklarini o‘zbek tilida tushunadi.
- **Budjetga mos mahsulot tanlash**: Masalan, foydalanuvchi *"500 000 so‘mgacha sovg‘a kerak"* deb yozsa, AI mavjud katalogdan aynan shu narx doirasidagi mahsulotlarni tanlab, nima uchun mosligini tushuntiradi.
- **Mahsulotlarni o‘zaro solishtirish**: Masalan, *"iPhone 15 bilan Samsung S24 ni solishtir"* yoki *"Dasturlash uchun qaysi noutbuk ma’qul?"*.
- **Anti-Hallucination Kafolati**: AI mavjud bo‘lmagan mahsulot, to‘qima narx yoki xususiyatlarni o‘ylab topmaydi. Agar ma’lumot katalogda bo‘lmasa, buni ochiq aytadi.
- **Interaktiv Chat Kartalari**: AI o‘z xabari ichida mahsulot kartasini, rasmini, narxini ko‘rsatadi va foydalanuvchi to‘g‘ridan-to‘g‘ri chat ichidan *"Savatchaga qo‘shish"* yoki *"Ko‘rish"* tugmasini bosa oladi!
- **Dual Engine (Ikki tomonlama AI tizimi)**:
  1. Google Gemini API bilan to‘g‘ridan-to‘g‘ri integratsiya (agar `.env` faylida `GEMINI_API_KEY` ko‘rsatilsa).
  2. O‘rnatilgan aqlli o‘zbekcha semantik NLP qidiruv mexanizmi (hech qanday API kalit talab qilmasdan, hatto oflayn rejimda ham 100% aniqlikda ishlaydi).

### 🛡️ 2.7. Admin Dashboard (Boshqaruv Paneli)
Himoyalangan professional dashboard:
- **Tahlil va Statistika**: Jami savdo tushumi (UZS), buyurtmalar soni, katalogdagi mahsulotlar soni, toifalar bo‘yicha taqsimot ko‘rsatkichlari.
- **Mahsulotlar boshqaruvi**: Yangi mahsulot qo‘shish (nom, narx, chegirma narxi, toifa, rasm, tavsif, ombor qoldig‘i), mavjud mahsulotlarni tahrirlash va o‘chirish.
- **Buyurtmalar nazorati**: Tushgan barcha buyurtmalar ro‘yxati, mijoz manzili, tanlangan tovarlar va buyurtma holatini real vaqtda o‘zgartirish (`Kutilmoqda` → `Tayyorlanmoqda` → `Yetkazilmoqda` → `Yetkazib berildi` → `Bekor qilindi`).
- O‘zgarishlar doimiy `server/data/marketplace.json` ma’lumotlar bazasida saqlanadi.

## 🚀 4. O‘RNATISH VA ISHGA TUSHIRISH

### 4.1. Talablar:
- Node.js (v18 yoki undan yuqori)
- NPM yoki Yarn

### 4.2. Loyihani yuklab olish va o‘rnatish:
```bash
# Loyiha papkasiga o'ting:
cd "c:\Users\user\Desktop\887888888485125454"

# Kutubxonalarni o'rnatish:
npm install
```

### 4.3. Ishga tushirish:

**Variant 1: Ishlab chiqish rejimi (Development):**
```bash
npm run dev
```
Bu buyruq bir vaqtning o‘zida backend API serverini (`http://localhost:5000`) va tezkor Vite frontendini (`http://localhost:3000`) ishga tushiradi.

**Variant 2: Ishlab chiqarish rejimi (Production / Taqdimot uchun eng qulayi):**
```bash
# Loyihani yig'ish:
npm run build

# To'liq Full-Stack serverni ishga tushirish:
npm start
```
Brauzerda `http://localhost:5000` manzilini oching. Barcha funksiyalar (frontend, backend va AI) bitta portda ishlaydi!

## 🌐 5. INTERNETGA JOYLASHTIRISH (DEPLOYMENT GUIDE)

Loyihani internetga bepul va 5 daqiqada joylashtirish mumkin:

### 1-usul: Render.com (Tavsiya etiladi — Full-Stack)
1. GitHub da yangi repozitoriy ochib, loyihani push qiling:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Mini Marketplace + AI"
   git remote add origin https://github.com/SIZNING_PROFILINGIZ/mini-marketplace-ai.git
   git push -u origin main
   ```
2. [Render.com](https://render.com) ga kiring va **"New Web Service"** tugmasini bosing.
3. GitHub repozitoriyangizni tanlang.
4. Quyidagi sozlamalarni kiriting:
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Environment Variable**: `PORT=5000`, `GEMINI_API_KEY=(ixtiyoriy)`
5. **"Deploy Web Service"** tugmasini bosing. Render sizga bepul `https://mini-marketplace-ai.onrender.com` manzilini beradi.

### 2-usul: Vercel (Frontend uchun)
1. [Vercel.com](https://vercel.com) ga kiring va repozitoriyangizni import qiling.
2. Framework: **Vite** ni tanlang va **Deploy** tugmasini bosing.
